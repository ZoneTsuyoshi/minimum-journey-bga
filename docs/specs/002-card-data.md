## 目的

MINIMUM JOURNEY の全カード（画像 72 枚、カード番号 001〜058 と裏面）のデータを 1 本の仕様書にまとめる。後続の実装（カード定義データの作成、効果の実装）がこの文書だけを見て進められるようにし、`CLAUDE.md` の用語集で保留していた英語識別子を確定させる。

## スコープ

- 対象: カードのデータ項目の定義、列挙値（シンボル・効果タイミング）と英語識別子、全カード一覧、カードごとの詳細（効果テキストの原文転記）、絵柄違いの内訳、集計の検算、カード単位で解釈が定まらない点の洗い出し。
- 対象外: 個々の効果をプログラムでどう実装するか、フェイズ進行などのゲーム全体のルール（別の仕様書で扱う）。効果テキストを本書の言葉で解釈・再定義することもしない。解釈が必要な点は「未確定事項」として作者に質問する。

## 仕様

### 1. 根拠と読み方

- 根拠はカード画像 `data/cards/*.png` と、その書き起こし（画像 72 枚分）。ルールブック `data/rulebook/minimum_journey_rulebook.pdf` と食い違う場合はルールブックを正とするのが原則だが、本書ではカード画像を優先した箇所（018 のカード名）がある。食い違いは「未確定事項」に挙げた。
- 効果テキストは書き起こしの**原文をそのまま**転記している。言い換え・要約・補完はしていない。
- 探査コスト欄に表示される「縦長の四角」は 7 セグメント風フォントの数字「0」であり、初期カード（001・002・003）の探査コストは **0** として扱う（画像で確認済み。未確定事項ではない）。他カードのコスト数字（2 / 4 / 6 / 8 / 10）も同じ 7 セグメント風フォントである。
- 探査力（歯車）や名声（星）の右上にある小さな「+」バッジは、そのカードが探査力変動／名声変動の効果を持ち、値が変動しうることを示す印である（018, 047 の画像で確認済み）。探査力の歯車の「+」バッジは、**そのカード自身の探査力が変わる**印である（作者回答 2026-10-13 第4回、未確定事項 No.2）。
- 探査力の歯車に付く**小さな歯車の装飾**は、「+」バッジとは別の印で、**他のカードの探査力を変える**ことを示す。右上 = 増加させる、右下 = 減少させる、右上・右下の両方 = 増減する（作者回答 2026-10-13 第4回、未確定事項 No.2）。019（右上・右下）、030（右下）、048（2 個）に付く。他のカードに見落としがないかの点検は未了である。
- **探査場**は、**探査場の列**（探査列）、**探査山札**（の上のカード）、**056** の総称である（作者回答 2026-10-13 第4回、未確定事項 No.15・41）。カード文面が「探査場」と書く効果は探査山札の上のカードと 056 を含み、「探査場の列」と書く効果は列のカードだけを指す。探査列と探査山札は意図的に分けて呼ばれている。
- 一般則: 探査力（探査出力）は、「探査出力の決定」で決まってから変わらない（作者回答 2026-10-13 第4回、未確定事項 No.33）。探査フェイズ中に準備場のカードが除外されても、探査出力から差し引かない。
- 一般則: 優先度が同じ効果が互いに影響し合うときは、互いに無効化される（作者回答 2026-10-13 第4回、未確定事項 No.49）。ドロー時効果の優先度の体系は別仕様書 010-draw-effect-priority.md（T-010）で定める。054 は他のカードの影響を受けず最優先で、039・053 でも無効化されない。
- 同じカードは複数枚存在しない（各カードは 1 枚。作者回答 2026-10-13 第4回）。同名カードの重なりや、同じカードを自分自身に適用する状況は起こりえない。

### 2. データ項目の定義

1 枚のカード（1 つのカード種別）は次の項目を持つ。

| 項目 | 型 | 説明 |
| --- | --- | --- |
| カード番号 | 3 桁文字列 | カード右下の 3 桁（`001`〜`058`）。裏面は番号を持たない |
| 名称 | 文字列 | カード上部のカード名（日本語。原文） |
| 英語識別子 | snake_case 文字列 | コード上の ID。本書で確定させる。カード名の英訳案は各カード詳細に併記 |
| シンボル | 列挙値の配列（1〜5 個） | 左側の丸いシンボルアイコン。複数持つカードは 051 のみ（5 個） |
| 探査コスト | 整数または なし | 獲得に必要な探査出力。初期カードは 0、漂流カードは 2 / 4 / 6 / 8、未確認帯域は 10、お守りは「なし」（コスト欄が無い） |
| 探査力 | 整数 | 左下の歯車の数値（印刷値）。探査力変動効果で変動しうる |
| 名声 | 整数 | 右下の星の数値（印刷値）。名声変動効果で変動しうる |
| 探査力の+バッジ | 真偽 | 歯車の右上の「+」。そのカード自身の探査力が変わる（探査力変動効果を持つ）印 |
| 名声の+バッジ | 真偽 | 星の右上の「+」。名声変動効果を持つ印 |
| 探査力の歯車の装飾 | 列挙値 | 歯車に付く小さな歯車の装飾。他のカードの探査力を変える印。なし / 右上（増加）/ 右下（減少）/ 両方（増減）。019 = 両方、030 = 右下、048 = 両方（2 個） |
| 効果タイミング | 列挙値の配列（0〜2 個） | 効果テキスト冒頭の【】ラベル。複数持つカードは 2 つのラベルが並ぶ |
| 効果テキスト | 文字列 | 原文。複数ラベルを持つカードは `／` で区切って記載（後述の注意参照）。効果なしは「なし」 |
| 下部アイコン補助表記 | 文字列 | カード下部（探査力・名声の間）の図解に添えられた文字（`+3`, `LAST` など）。文字が無い場合は「なし」 |
| 枚数 | 整数 | そのカード種別が存在する枚数 |
| 画像ファイル | 文字列 | `data/cards/` 内のファイル名 |

注意: 効果テキストの `／` は書き起こし側の区切り記号であり、カード画像では改行で区切られている。複数ラベルを持つカードで「どのラベルがどの文に対応するか」が画像から推定のものは、各カード詳細に明記し未確定事項に挙げた（040, 041, 042 など。第4回で暫定案了承）。

#### 3.4 表記の凡例（角括弧表記）

効果テキスト中のアイコンは、書き起こしで角括弧表記にされている。対応は次のとおり。

| 表記 | 意味・画像上のアイコン |
| --- | --- |
| [地球] [太陽系] [天の川銀河] [乙女座銀河団] [ラニアケア超銀河団] [未確認帯域] [お守り] | 各シンボルのアイコン（3.1 参照） |
| [探査力] | 歯車アイコン |
| [名声] | 星（ギザギザの円）アイコン |
| [探査コスト] | 青い円に×（照準の中に×）のアイコン。047「[未確認帯域]の[探査コスト]-2」で探査コストを指すことを確認済み。カード右側のコスト欄の照準マーク（中は「+」）とは中の記号が異なる |
| [探査力変動] [名声変動] | 枠付きラベル（019, 048）。効果タイミングと同じ |
| [国旗] [乗組員] | 016・017 の文中アイコン。黒い旗のアイコンは国旗（001）、白抜きの宇宙飛行士のアイコンは乗組員（002）を指す（確定、作者回答 2026-10-13 第3回。未確定事項 No.1）。書き起こしでは不明アイコンと記録されていたが、効果テキストは [国旗] [乗組員] に置き換えた |
| 【…】 | 効果タイミングのラベル |

下部アイコンの補助文字: `+3` `+2` `+1`（加算量）、`-1` `-2`（探査コスト減）、`LAST`（最後）、`FIRST`（最初）、`LAST DRAW`、`WAIT`、`STOP`、`MUST`、`LEFT`（左隣）、`MIN`（最小）、`COPY`、`0`、`×`。これらは画像上の文字の転記であり、意味の解釈は本書では行わない。

### 5. カードごとの詳細

英訳案は仮の呼称であり、UI 文言として確定するものではない。「下部アイコン」「書き起こしの要確認」は書き起こしの記録をそのまま載せている。下部アイコンの記述は図の説明であり、効果の定義ではない。

#### 001 国旗（Flag / `flag`）

- シンボル: 地球（`EARTH`）
- 探査コスト: 0（コスト欄の「縦長の四角」は 7 セグメント風の 0）
- 探査力: 0／名声: 3
- +バッジ: なし
- 効果タイミング: なし
- 枚数: 4
