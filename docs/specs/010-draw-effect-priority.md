## 目的

準備フェイズで 2 人以上が同時に「ドロー」した回は、ドローした各プレイヤーが引いたカードの【ドロー時】効果を解決する。ドロー時効果には互いに干渉するものがあるが、複数人が同時に引いたときの解決順は紙のルールブックに書かれていない。この仕様書は、作者回答「互いに影響する効果は優先度をつける想定」に沿った**優先度体系**を定める。

第4回の作者回答（2026-10-13）で、案 A（6 段階）が大枠で了承され（D1）、054 の独立化（D2）、P5 の区分（D3）、同優先度の処理順（D4・D5）などの修正が示された。第5回の作者回答（2026-10-13）では、残っていた質問（053 は戻されても残る、054 は 043 で戻されると残らない、054 があるとき 049 はドロー固定、山札 0 枚はドローできない、008 はコピー元のレベルで解決、046 の付加カードのドロー時効果は発動、043 の判断は同時・非公開など）に答えがあり、反映した。第7回の作者回答（2026-10-13）では、第5回で追加した質問 Q-22〜Q-26 に「はい」の回答があり（J1〜J5）、046 の処理位置（P3 より前）、付加カードの遡及なし、山札 0 枚のプレイヤーの準備終了の打ち消し、039 の判定に使うシンボル、008 の対象を選ぶ列を反映した。本書は**確定した部分と、まだ提案・未確定のままの部分が混在している**。

補足:

- D4 の解釈: お守り所持者からの時計回りの距離を d（所持者 = 0、時計回りの隣 = 1、…）とすると、**d の大きい順**に処理し、所持者が最後になる。探査手番決定の第3条件（お守り所持者が最優先）とは**逆向き**である。
- D8: 各カードは 1 枚ずつしか存在しない。同名カード同士の重なり（053 + 053、043 + 043、049 + 049、039 + 039 など）は**起こりえない**。
- 002 未確定事項 No.49 の旧暫定案（「039 と 053 が同時なら 053 を優先して他プレイヤーの効果を止める」）は、F3 に合わせて 002 側で更新済み（2026-10-13）。
- D7 は 002 No.48 の暫定案（043 で戻した後に準備したカードの効果は「発動する」）と食い違う。§8 申し送り参照。
- H2 と D2 の関係: D2「054「ビッグバンの種」は他のカードの影響を受けずに最優先され、039, 053でも無効化されません」は 039・053 による無効化についての回答。H2「残らない」は 043 で山札に戻された場合の回答。両方を満たすため、054 は 039・053 では無効にならないが、043 で戻されると強制ドローは残らない。D2 を根拠に「043 でも残る」と読むことはしない。
- H1 と D6: 043 で戻されても作用が残るのは P1 の 039・053（D6・H1）。054（P0）は戻されると残らない（H2）。
- H5: 008 がコピーするのは探査場の列にあるカードで、列にあるカードを同じ回に誰かが引くことはない（同じカードは複数枚存在しない）。このため、024 と 024 をコピーした 008、007 と 007 をコピーした 008 は同じ回に出ない。
- J1〜J5 の範囲: J1 が確定するのは、046 の処理が 024（P3）より前であることと、付加カードが P3〜P6 相当（007 のような P5-順番の効果を含む）のときは本来のレベルで解決すること。付加カードが 054（P0 相当）だった場合は質問文に含まれず、Q-22 に残す。J5 が確定するのは、008 の対象を「効果を解決する時点の列」から選ぶこと。008 がコピー元を選ぶのがいつか（コピー元のレベルが決まる前に選ぶ必要がある点）は質問文に含まれず、Q-27 に切り出した。
- H7 の確認内容（作者の指摘どおり「起こりえない」として閉じる）: 028・029 はどちらも「自分は、次の準備選択において…」で対象は引いた本人。1 人が 1 回のドローで得るドロー時効果は、引いたカード 1 枚分と、046 の付加カード 1 枚分まで。046 自身は 028 でも 029 でもなく、008 は 1 枚の効果しかコピーしないため、同じプレイヤーに 028 と 029 が同時にかかる経路はない。

### 5. 同じ優先度の効果が複数あるときの規則

#### 5.1 規則（確定）

【確定】D3・D4・D5・D8:

1. **他プレイヤーに影響を与えない効果は、全員同時に処理する**（D5）。P5-同時、P6 がこれに当たる。
2. **他プレイヤーに影響しうる効果は、同優先度の中で順番に処理する**（D3）。D3 が明示したのは P5 の探査場の列の選択（007、008 で 007 をコピーした場合）。ただし同じ回に出るのは 1 つだけ（H5）。

4. D4 は「同優先度の処理は」と一般に述べているので、**順番に処理する必要がある同優先度の効果すべてに適用する**（P1〜P4 を含む）。ただし D8・H5 により各カードは 1 枚ずつしか存在せず、007 と 007 をコピーした 008 も同時に出ないので、現行カードでは同優先度で順番の問題が生じる場面はない。D4 の順序は確定ルールとして残す。P1（039 と 053）は F3 が結果を順序に依存しない形で定めているので、順序を用いない。P2（043）の実行順は、別々の山札を対象とするので結果に影響しない。
5. **F3 は一般則**（D8）: 同優先度の抑止効果は互いに無効にし合い、それでも各自の抑止作用は残る。同名カード同士の重なり（053 + 053、039 + 039 など）は起こりえない。

1. 準備選択（①）・選択開示（②）で、ドローしたプレイヤーが山札の上から 1 枚を表向きで引き、準備場に置く。ストップしたプレイヤーが引いた裏向きのカードは準備したカードではなく、効果は無効（F6）。①で、前回の回に 054 が有効（引かれ、かつ 043 で山札に戻されなかった。H2）だった場合は、全員が「ドロー」を選ぶ。このとき**強制ドローさせられたプレイヤーのうち、その時点で準備終了していた全プレイヤーの準備終了は打ち消される**（N38）。山札が 0 枚のプレイヤーは、強制されてもドローできず、何も起きない（H4）。山札 0 枚で準備終了済みのプレイヤーの準備終了も打ち消されるが、打ち消されても、ドローできず何も起きない（J3）。

#### 6.4 任意効果と非公開情報

- 「してもよい」を含む効果（009、014、020、035、036、043、050 など）は、持ち主だけが選択する。選択しなかった場合の工程（シャッフルを行うか）は 001 §11・Q-28 に従う。

- 抑止（P1）の判定結果は公開情報としてよい（引いたカードは全て表向きで、条件は公開された情報だけで決まる）。

### 8. BGA 実装への申し送り
