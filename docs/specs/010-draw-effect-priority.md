## 目的

準備フェイズで 2 人以上が同時に「ドロー」した回は、ドローした各プレイヤーが引いたカードの【ドロー時】効果を解決する。ドロー時効果には互いに干渉するものがあるが、複数人が同時に引いたときの解決順は紙のルールブックに書かれていない。この仕様書は、作者回答「互いに影響する効果は優先度をつける想定」に沿った**優先度体系の案**を示す。

**この文書は作者に判断してもらうための提案書であり、決定事項ではない。** 文中では次の印で区別する。

| 印 | 意味 |
| --- | --- |
| 【確定】 | 作者回答（2026-10-13）、ルールブック、または 001 / 002 で確定済みの事実。原文を広げて解釈しない |
| 【カード文面】 | カードの効果テキストにそのまま書かれていること（解釈を足していない） |
| 【提案】 | この文書の案。作者が採否を決める |
| 【未確定】 | 材料が足りず、案も仮置きにとどまるもの。「未確定事項」の節に質問として挙げる |

## スコープ

- 対象: 同じ回に複数人が引いたドロー時効果の解決順（優先度）の案、同優先度の扱い、解決手順、検証例、BGA 実装への申し送り
- 対象外: 各カード単体の効果解釈（002 の未確定事項で扱う）、準備フェイズ全体の流れ（001 §5）、BGA の状態遷移・通知の詳細設計（T-006 / T-008）

#### 3.1 干渉の向きによる分類

【提案】20 枚を「その効果が何に作用するか」で分類する。1 枚が複数の分類に入ることがある。

| 分類 | 作用先 | 該当カード | 備考 |
| --- | --- | --- | --- |
| (a) 他のドロー時効果を無効化・制限する | このドローの他プレイヤーのドロー時効果 | 039、053 | 039 は乙女座銀河団を持たない効果を、053 は他プレイヤーの効果を全て止める（【カード文面】） |
| (b) このドローで引いたカードそのものを動かす | 他プレイヤーがこのドローで引いたカード | 043 | 戻された側のカードの効果は消える可能性がある。戻した後に準備したカードの効果の扱いは未確定（F8） |

#### 3.2 干渉マトリクス（グループ単位）

【提案】行が「作用する側」、列が「作用される側」。記号は「影響あり」「影響なし」「不明」。カード文面から読み取れる範囲に限り、読み取れない組み合わせは「不明」とし、推測で確定させない。

グループ: A = 抑止（039・053）、B = 引き戻し（043）、C = 他者への追加準備（024）、D = 探査場（007・008・036）、E = 自分の山札・準備場（c の 9 枚。008 のコピー先を除く）、F = 次の準備選択を縛る（028・029・049・054）

| D 探査場 | 影響なし | 影響なし | 影響なし | 影響あり（036 が列のカードを入れ替えると、007 が選んだカードが列から消えうる。036 同士、007 同士も同様。Q-8） | 影響なし | 影響なし |

読み取り方:

- 行 A（抑止）は、作用先が「ドロー時効果を持つカードの効果」全般なので、列 B〜F すべてに影響する。これが優先度の最上位に置く理由の根拠となる。
- 行 C・E・D の大部分は「影響なし」、つまり**別のプレイヤー同士の順序は結果に影響しない**。優先度を細かく定める必要がある干渉は、行 A、行 B、列 D（探査場）、行・列 F の一部に限られる。

### 4. 優先度体系の提案

数字が小さいほど先に解決する。いずれの案も、【確定】F2（039 が 043 より先）と F3（039 と 053 は同レベル、相互に無効、053 の全体無効は残る）を満たすことを前提に作る。

#### 4.1 案 A: 段階的な優先度表（6 段階）

【提案】干渉の向き（§3）に従って、「他の効果の有無そのものを決める効果」ほど先に解決する。

| レベル | 名称 | カード | 根拠 |
| --- | --- | --- | --- |
| P1 | 抑止（他のドロー時効果を止める・制限する） | 039、053 | 他の全てのドロー時効果の「発動するか」を決めるので最上位に置く（§3.2 の行 A）。F3 により 039 と 053 は同レベル。F2 により 043 より先 |
| P2 | 引き戻し（このドローで引いたカードを動かす） | 043 | 【カード文面】「ドロー時効果を発動する前に決める」。戻されたカードの効果は P3 以降に回らなくなるので、P3 以降より前に決着させる。P1 の後に置くのは F2 と整合し、また 053 に止められた 043 は発動しないという文面どおりの帰結になる |
| P3 | 他プレイヤーへの追加準備 | 024 | 作用先がこの回にドローしていないプレイヤーで、他の効果と対象が重ならない（§3.2 の行 C）。順序が結果を変えないので、他者に作用する効果としてまとめて P2 の後、自分だけの効果の前に置く（決定論的にするための配置） |
| P4 | 探査場の列の入れ替え | 036 | 007 が「列のカードを選ぶ」前に列を確定させる。007 がカードを選んだ後で 036 が入れ替えると、選択が無意味になりうる（Q-8） |
| P5 | 自分の山札・準備場の操作、探査場の列の選択 | 005、007、008（コピー）、009、010、014、020、035、046、050、052 | 他プレイヤーに影響しない（§3.2 の行 E）か、P4 の後で行うべきもの（007）。別プレイヤー間では順序が結果を変えない |

### 5. 同じ優先度の効果が複数あるときの規則

#### 5.1 選択肢

| 方式 | 内容 | 長所 | 短所 |
| --- | --- | --- | --- |
| (i) 同時解決 | 同レベルの効果は、そのレベル開始時点の状態に対して全て同時に判定・適用する。互いの結果は見ない | F3（039 と 053 が互いに無効）と同じ考え方。順序に依存しない | 効果の対象が重なる場合（036 同士など）は同時に適用できない |
| (ii) 席順 | お守り所持者から時計回りに 1 枚ずつ解決（001 Q-8 の暫定案、探査手番決定の最終条件と同じ順） | どんな組み合わせでも決定論的に動く | 席順が結果を左右する。ルールブックに根拠がない |
| (iii) プレイヤーの選択 | 同レベルの効果の持ち主が解決順を相談・選択 | 柔軟 | BGA で合意を取る手間が大きく、ゲーム性としても不明 |

#### 5.2 提案

【提案】

1. **P1（抑止）は (i) 同時解決**。F3 と整合する。具体的には「各抑止カードの作用は、そのカード自身が他の抑止カードに無効にされても残る」と定める（F3 の「お互いのカード効果が無効となると同時に、…「スーパーフレア誘発装置」の効果で全て無効になる」の読み）。
2. **P2（引き戻し）は (i) 同時**: 引き戻すかどうかの決定は全員が非公開・同時に行い、全員の決定が出揃ってから公開して実行する（【カード文面】043「発動する前に決める」と 002 未確定事項 No.48 の暫定案 (b)(e) に合わせる）。実行は席順だが、結果が順序に依存しない（別々の山札に対する処理）。
3. **P3〜P6 は、別プレイヤー間では順序が結果に影響しないので、(i) 同時**として扱ってよい。実装上は決定論のためお守り所持者から時計回りで処理してよい（結果は同じ）。
4. **順序が結果を左右する同レベルの組み合わせ**（036 同士、007 同士、049 同士、同一プレイヤーが複数の効果を持つ場合）は、現時点の材料では決められない。暫定案はお守り所持者から時計回り。作者に判断を仰ぐ（Q-7、Q-8、Q-10、Q-12）。

#### 5.3 F3 を一般則にできるか

F3 は 039 と 053 の組み合わせについての裁定である。次の 2 通りの読みがあり、**どちらが作者の意図かは文面から分からない**。

| 読み | 内容 | 帰結 |
| --- | --- | --- |
| 読み G（一般則） | 「同じ優先度の抑止効果は互いに無効にし合い、それでも各自の抑止作用は残る」を P1 全体の規則とする | 053 + 053 は互いの効果が無効になり、かつ双方の抑止作用が残る（他の全員の効果も止まる）。039 + 039 は互いに乙女座を持つので無効にならない |
| 読み S（特例） | 039 と 053 の 2 枚に限った裁定。それ以外の同レベルは別途決める | 053 + 053 や、同レベルを新設する場合は別に裁定が要る |

【提案】読み G を採用する。理由は、(1) 053 + 053 のように「同じカード 2 枚」が起こりうるのに特例では穴が残る、(2) 実装を「抑止カードの作用を同時に評価する」1 つの関数にできる、の 2 点。ただし F3 の範囲を超える拡張なので、作者の確認を要する（Q-4、Q-5）。P2 以降のレベルにまで「互いに無効」を広げることは根拠がなく、提案しない（043 × 043 は Q-6）。

### 6. 解決手順の提案

案 A を前提とする。

#### 6.1 手順

【提案】

1. 準備選択（①）・選択開示（②）で、ドローしたプレイヤーが山札の上から 1 枚を表向きで引き、準備場に置く。ストップしたプレイヤーが引いた裏向きのカードは準備したカードではなく、効果は無効（F6）。
2. ドローしたプレイヤーが 1 人だけなら、そのカードを横向きにして終了。以下の手順は行わない（F5）。2 人以上なら 3 へ。
3. **公開**: このドローで引かれた全てのカード D（持ち主つき）を確定する。ドロー時効果を持たないカード（051 など）は以降の対象外。
4. **P1 抑止の判定**: D の中の 039・053 を「抑止カード」とする。D の各カードについて、全ての抑止カードの条件を満たすときだけ「有効」とする。

5. **P2 引き戻し**: 有効な 043 ごとに、他のプレイヤーが自分のこのドローのカードを戻すかを、非公開・同時に決める。全員が決めたら公開して実行する。戻したプレイヤーは、カードを山札に戻してシャッフルし、1 枚準備する。戻されたカードの効果は以降の手順から外す。
6. **P3 他プレイヤーへの追加準備**: 有効な 024 ごとに、既に準備終了しているプレイヤーが、自分の山札の上から 1 枚を準備する。
7. **P4 探査場の入れ替え**: 有効な 036 を解決する。
8. **P5 自分の山札・準備場の操作、探査場の列の選択**: 有効な 005・007・008・009・010・014・020・035・046・050・052 を解決する。別プレイヤー間は同時でよい。007 は P4 の後に列のカードを選ぶ。
9. **P6 次の準備選択の制約**: 有効な 054・028・029・049 の制約を、次の準備選択に対する記録として残す。054 の記録がある場合、029 の「ストップしか選べない」は無視する（【カード文面】054）。
10. ①へ戻る（001 §5 ③-2）。

    D = [c for c in drawn_cards if c.has_on_draw_effect]

    pods = [c for c in D if c.id == 043 and c.valid]

#### 6.4 任意効果と非公開情報

- 「してもよい」を含む効果（009、014、020、035、036、043、050 など）は、持ち主だけが選択する。選択しなかった場合の工程（シャッフルを行うか）は 001 §11・Q-28 に従う。
- 別プレイヤー間は順序が結果を変えないので、P5 の任意効果は**複数のプレイヤーが同時に（非公開で）選択してよい**。待ち時間を減らせる。
- 山札を見る効果（005、010、020、035、036、050、052）で見たカードの内容は、持ち主だけが知る情報とする。他プレイヤーには「山札の上のカードを見た」「山札をシャッフルした」などの公開できる事実だけを伝える。036 の「表にする」は公開情報。
- 043 の「戻すか」は、先に決めた人の選択を見て後の人が決める、ということが起きないよう、非公開・同時に決める（002 未確定事項 No.48(b)(e) の暫定案と同じ）。
- 抑止（P1）の判定結果は公開情報としてよい（引いたカードは全て表向きで、条件は公開された情報だけで決まる）。

### 7. 具体例による検証

案 A（§4.1）と §5・§6 の規則を適用する。プレイヤーは A・B・C・D、いずれも同じ回に初めてドローした（ストップ済みと明記したプレイヤーを除く）。「作者裁定との一致」欄は、【確定】F2・F3・F4 と照合した結果。

#### 例 1: 039 + 043（F2 の検証）

A が 039、B が 043、C が 005 を引いた。

1. P1: 039 の条件は「[乙女座銀河団]を持つ」。A の 039 と B の 043 は乙女座銀河団を持つので有効。C の 005 は太陽系なので無効。
2. P2: 043 は有効。A と C が、自分のカードを戻すかを非公開・同時に決める。C は無効になった 005 を戻して別のカードを準備することもできる。A が 039 を戻した場合でも、P1 の判定は P2 より前に確定しているので取り消さない（【提案】）。
3. 戻した後に準備したカードの効果は、発動するなら 039 の絞り込みの対象になる（Q-3）。

作者裁定との一致: F2「039 は 043 より優先」と矛盾しない（039 の判定が 043 の決定より前）。ただし「優先」の具体的な意味（Q-1）と、039 が戻された場合の扱い（Q-2）は【未確定】で、上の結果はそれを【提案】で埋めたもの。

#### 例 2: 039 + 053 + 043（F3・F4 の検証）

A が 039、B が 053、C が 043 を引いた。

1. P1: 抑止カードは 039 と 053 の 2 枚。A の 039 は乙女座銀河団を持つが 053 の持ち主が自分以外なので 053 の条件を満たさず、無効。B の 053 は乙女座銀河団を持たないので 039 の条件を満たさず、無効。C の 043 は乙女座銀河団を持つが 053 の持ち主が自分以外なので無効。
2. 無効になっても 039・053 の作用は残るので、C の 043 は発動しない。P2 以降に有効な効果は残らない。

作者裁定との一致: F3「お互いのカード効果が無効となると同時に、他プレイヤーのドロー時効果も 053 の効果で全て無効」と一致。F4「その『ドロー』における全てのプレイヤーのドロー時効果が発動しなくなる」とも一致（A・B・C のドロー時効果がいずれも発動しない）。

#### 例 3: 053 + 043

A が 053、B が 043、C が 005 を引いた。

1. P1: 053 の条件により、A 以外のカードは無効。B の 043 も C の 005 も発動しない。A の 053 は他プレイヤーのみを対象にするので A 自身は有効だが、他にやることがない。

#### 例 4: 039 + 乙女座銀河団の他カード

A が 039、B が 035、C が 036、D が 005 を引いた。

1. P1: 035・036・039 は乙女座銀河団を持つので有効。005 は無効。

作者裁定との一致: 裁定なし。【カード文面】039 の帰結。

#### 例 5: 024 と他のカード

A が 024、B が 005 を引いた。C・D はこの回より前にストップ済み。

1. P1: 抑止なし。

#### 例 6: 次の準備選択を縛るカード同士（028・029・054）

A が 028、B が 029、C が 054 を引いた。

2. P6: 054 を先に記録する。全員が次の準備選択で「ドロー」を選ばなければならず、既に準備終了しているプレイヤーも同様、他のカード効果による「ストップ」は無視。B の 029 の「ストップしか選べない」は無視される。A の 028（ドローしか選べない）は 054 と矛盾しない。

#### 例 7: 049 + 049

A が 049、B が 049、C が 028 を引いた。

### 8. BGA 実装への申し送り

実装の詳細には踏み込まない。T-006（状態遷移）と T-008（カード効果）が参照する前提を示す。

1. **優先度をカード定義のデータ項目として持つ【提案】**: 002 のカード定義に「ドロー時効果の優先度」（案 A なら 1〜6 の整数、ドロー時効果を持たないカードは空）を追加する。各カードの値は §4.1 の表のとおり。008 のみ「コピー元の優先度を継承」を示す値にする。これにより、解決手順（§6.1）はデータ駆動で書ける。
2. **抑止の条件もデータで持つ【提案】**: 039 は「許可するシンボル」、053 は「持ち主が同じカードのみ許可」のように、抑止カードごとに「通すカードの条件」を持たせる。新しい抑止カードを足しやすい。
3. **同時に複数人が選択する状態【提案】**: P2（043 の「戻すか」）は全員が非公開・同時に決める必要があり、複数人が同時に行動できる状態（multiple active player）が要る。P5 の任意効果も、別プレイヤー間は順序が結果を変えないので、同時に選択させる案が成立する。ただし、P4・P5 で探査場の列を共有する効果（036・007）は、状態を分けて順に処理する。最終的な状態遷移の設計は T-006 に委ねる。
4. **公開・非公開の情報の分離【提案】**: 山札を見る効果の内容は持ち主にだけ通知する。043 の決定は公開前に他のプレイヤーへ漏らさない。
5. **未確定事項の影響**: Q-1〜Q-3（039 と 043 の関係、043 のあとに準備したカード）、Q-7〜Q-10（同優先度の順序、049）が確定するまで、T-008 の該当カード（039・043・036・007・049・046）の実装は保留にするのが安全。他のカードの実装は、本提案の P1〜P6 のレベル値を仮置きして先に進められる。
6. **002 の更新**: 002 の No.49 は F3 に合わせて更新済み。優先度をカード定義の項目として追加する場合は、本仕様書の確定後に 002 を別途更新する。
