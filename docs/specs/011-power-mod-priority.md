## 目的

探査フェイズの最初に行う「探査出力の決定」で、【探査力変動】効果をどの順に適用するかの体系を、作者に判断してもらうために**提案**する。【探査力変動】には「そのカード自身の探査力を増やす」ものと、「他のカードの探査力を書き換える・無効にする」もの（019 鉱石ミキサー、030 核熱ブースター、048 重力反転装置）があり、後者が同じカードに重なると適用順で結果が変わる。作者は個別の裁定を出したうえで「探査力変動系も優先順位つけた方が良いかも？」と述べている。

この文書は「作者に判断してもらうための提案書」である。確定している事実は【確定】、本書が示す案は【提案】と明記し、作者が決めるべき点は「未確定事項」にまとめる。

## スコープ

- 対象: 【探査力変動】効果の適用順（段階分け）、評価のタイミング、計算手順、検証例、探査力変動カードの歯車の装飾の点検、BGA 実装（T-008）への申し送り。
- 対象外: ドロー時効果の優先度（010）、【名声変動】の計算（名声変動は別途。ただし 019・048 の「名声変動効果を持つカードには発動しない」例外は本書で扱う）、探査手番の決定（001 §6-2）、UI の設計（準備フェイズ中の表示については §5 に申し送りのみ）。

### 3. 効果の分類と依存関係

#### 3-1. 分類

| 分類 | 内容 | 該当カード | 条件が依存するもの |

| (a) 自分自身の探査力を条件つきで増やす | 「+」バッジ。他のカードの探査力の値には依存しない | 016、017、018、022、023、032、033、040、041、042、044、045、057 | 下表 3-2 |
| (b) 他のカードの探査力を書き換える | 名声を探査力として扱い、そのカードの探査力変動効果を無視する | 019（次の 1 枚）、048（準備場の全てのカード） | 019 は準備の並び（次のカード）、048 は準備場全体。いずれも対象が名声変動を持つかどうか |

- 他のカードの**探査力の値**を変えるのは 019・030・048 の 3 枚だけで、対象は 019（次の 1 枚）、030（直前の 1 枚）、048（全て）である。
- 他のカードの**探査力の値を読む**のは 031 だけで、読む相手は直前の 1 枚である。したがって 031 は 019・030・048 の結果（および直前のカード自身の変動の結果）を受ける。
- (a) の自身変動は、他のカードの探査力の値に依存せず、自身の探査力変動効果が「発動する」場合にだけ作用する。019・030・048 は、この「発動する／しない」を決める。
- 023・042 は直前のカードの**シンボル**を見るので、直前のカードの探査力が書き換えられても結果は変わらない（効果が発動するか否かだけが影響する）。

### 4. 適用順の提案

#### 4-1. 満たすべき条件

### 6. 計算手順と検証

#### 6-1. 計算手順（案 A）

【提案】入力は、準備場の表向きのカードを準備した順に並べたもの（裏向きのカードは含まない）、お守り、ラウンド数、そのプレイヤーが半減するか。

```text
function computeExplorationOutput(player, round):
    # 0. 準備
    cards = 準備場の表向きのカードを準備した順に並べたもの   # 横向きは末尾にある。裏向きは含めない。
    for c in cards:
        c.sideways    = c が横向きか
        c.power       = 0 if c.sideways else 印刷された探査力   # 046 は付加カードの探査力を加算（未確定事項 No.3）
        c.fame        = 印刷された名声                           # 046 は付加カードの名声を加算（B4）
        c.hasFameMod  = c が名声変動効果を持つか                  # 032, 033, 041, 042, 045, 047 など
        c.active      = not c.sideways                           # 自身の探査力変動を評価してよいか
    live = cards から横向きを除いたもの                          # 「直前」「次」「n 枚目」はこの並びで数える

    # S1 書き換え（048 があれば 048 だけを処理する。019 は 048 に包含される）
    if 048 in live:
        for c in live:
            if not c.hasFameMod:
                c.power = c.fame
                c.active = false
    else if 019 in live:
        n = 019 の次のカード（cards 上の次。なければ何もしない）
        if n exists and not n.sideways and not n.hasFameMod:
            n.power = n.fame
            n.active = false

    # S2 無効化（S1 の「発動しない」には妨げられない）
    if 030 in live:
        p = 030 の直前の live のカード（なければ何もしない）
        if p exists:
            p.power = 0
            p.active = false          # 名声変動を持つカードでも同じ

    # S3 自身変動（準備した順）
    for c in live:
        if c.active and c is not 031:
            c.power += bonus(c)       # bonus は §2 の各カードの効果テキストどおり。057 はお守り側で扱う

    # S4 参照
    if 031 in live and 031.active:
        p = 031 の直前の live のカード
        031.power += (p.power if p exists else 1)

    # 合計 → お守り → 半減 → 下限
    total = sum(c.power for c in cards)                  # 横向きは 0
    total = total + お守りの探査力                       # 057: round == 1 なら 0、そうでなければ 1。058: 0
    if player は半減する（1 人だけドローしたプレイヤー）:
        total = floor(total / 2)
    return max(0, total)
```

`bonus(c)` の数え方（準備場の枚数・シンボル・位置）は 002 の確定事項に従う。枚数は `cards`（横向きを数え、046 の付加カードは数えない）で数え、「直前」「より前」「最初」は `live` の並びで判定する。
