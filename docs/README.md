## ドキュメントを書くときのルール

- 日本語で書く。
- 仕様書とルールブックが食い違う場合はルールブックが正。ルールブックに記載のない点は「未確定事項」として明記し、作者に確認する。
- BGA フレームワークに関する記述には、確認した公式ドキュメントの URL を添える。
